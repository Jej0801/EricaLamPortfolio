# Erica Lam - Mechanical Engineering Portfolio

A professional portfolio website showcasing mechanical engineering projects, skills, and experience.

## Features

- Responsive design that works on desktop, tablet, and mobile devices
- Smooth scrolling navigation
- Interactive project cards
- Skills showcase organized by category
- Contact information section
- Modern, professional design

## Sections

- **Home**: Hero section with introduction
- **About**: Personal background and expertise
- **Skills**: Technical skills organized by category (CAD & Design, Analysis & Simulation, Manufacturing, Core Competencies)
- **Projects**: Featured engineering projects with descriptions
- **Contact**: Contact information and social links

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Responsive Design

## Customization

To customize this portfolio for your use:

1. Update personal information in `index.html`
2. Replace project placeholders with your actual projects
3. Add your project images to `assets/images/`
4. Update contact information with your details
5. Modify color scheme in `assets/css/style.css` (CSS variables at the top)

## Structure

```
EricaLamPortfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── images/
│       └── (add your project images here)
└── README.md
```

## How to Use

Simply open `index.html` in a web browser to view the portfolio locally, or deploy to any web hosting service.
